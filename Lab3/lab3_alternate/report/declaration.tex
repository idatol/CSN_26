\subsection{Reflection}

ChatGPT was used for rephrasing sentences that sounded strange by generating
multiple ideas and selecting parts of those suggestions. This worked well,
although the complete generated sentences could almost never be used as they
were. Using AI for grammar checks was helpful for removing most spelling
mistakes, but a human spell check still had to be carried out.

Claude was used for checking the written code for errors and bugs. For the errors and bugs that was found, fixes were suggest with properly explained reasoning. 

Claude was used to improve the visualization of the data in the plots. This was manually checked and just reduced the time needed for the visualisation improvements.


GitHub was used to store, share, and version the code. This allowed us to work on the same code without having to send it through other messengers. It would have also allowed us to restore an old version in case needed to do so.
